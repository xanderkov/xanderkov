### Hi there

I'm **Alexander Kovel** — Senior MLOps Engineer building **ML platforms**, model serving and high-throughput GPU inference.

Currently @ **Wildberries**, ML Platform — LLM, speech, OCR and vision inference for content moderation.

#### Highlights
- Scaled the ML inference platform from **300 to 1,200 RPS**
- **3–4x faster OCR** on Triton (DALI preprocessing, TensorRT on H200), **3x faster** transcription preprocessing
- **10+ LLMs** in production (Qwen3, GLM 5 on 8×H200) behind a **LiteLLM gateway** with budgets, token limits and routing
- GPU fleet of A100/H100/H200: driver rollouts on 20 nodes, **NVIDIA MIG** partitioning, HAMi GPU sharing
- Previously @ **Alfa-Bank** — led **LLMStore**, LLM autoscaling on KServe + Knative, GitOps deployments with ArgoCD

#### What I work on
- Serving models at scale with **Triton, vLLM, SGLang, TensorRT**
- GPU infrastructure on **Kubernetes**: MIG, GPU sharing, capacity planning
- LLM gateways and platform tooling: **LiteLLM**, MCP servers for AI agents
- Optimizing CV services in Python and C++, accelerating GPU-bound workloads
